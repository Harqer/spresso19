# Engineering & Design Principles

This directory contains the universal, cross-cutting rules that govern how code is written and how UI is designed in this project.

## Active Principles
- [[principles/ui-immersion]] - Rules for customer UI and hiding technical jargon
- [[principles/zero-mock-data]] - Strict mandate against using fallback stubs or fake responses
- [[principles/enterprise-architecture]] - High availability, caching, and resiliency standards
- [[principles/no-emojis-in-ui]] - Enterprise design system mandate
- [[principles/ci-dependabot-compatibility]] - Avoiding custom AI scripts that interfere with standard CI bots
