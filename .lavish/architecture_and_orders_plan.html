PostgreSQL "orders" Table Evolution

Column Name SQL Type Drizzle Schema Type Purpose
id SERIAL (PK) serial().primaryKey() Primary order identifier
user_id TEXT text().notNull() References Firebase Auth UID
total_amount NUMERIC numeric().notNull() Total order cost
status TEXT text().notNull() Standard: IN_TRANSIT, DELIVERED, etc.
items TEXT text() JSON string of products & quantities
return_status TEXT text() Returns state: NONE, REQUESTED, APPROVED
return_reason TEXT text() Sizing/Defective description
reminder_set BOOLEAN boolean().default(false) Alert state set (Active/Inactive)
reminder_time TEXT text() Time selected for alert notification

Firebase Cloud Firestore Root Collections

Production-ready flattened schema mapping that safeguards against race conditions, decouples cart/review dependencies, and stores snapshot items for historical receipt integrity:

1. products (Root Collection)

Active store inventory items. Reviews are decoupled to separate root collections.

{
  "name": "Minimalist Wireless Headphones",
  "description": "Noise-canceling over-ear headphones...",
  "price": 149.99,
  "compareAtPrice": 199.99,
  "category": "electronics",
  "stockCount": 42,
  "ratings": { "average": 4.7, "count": 128 }
}

2. users (Root Collection)

Profile records mapping authentication credentials and verified shipping targets.

{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "role": "customer",
  "shippingAddresses": [
    { "id": "addr_1", "street": "123 Main St", "isDefault": true }
  ]
}

3. carts (Root Collection)

Flat mapping supporting local storage / guest checkout sessions seamlessly.

{
  "updatedAt": "2026-08-10T12:20:00Z",
  "items": [
    { "productId": "prod_123", "name": "Headphones", "quantity": 1 }
  ],
  "cartTotal": 149.99
}

4. orders (Root Collection)

Historical immutable receipts containing fully snapshotted product details.

  "userId": "user_abc123",
  "status": "processing",
  "pricing": { "subtotal": 149.99, "total": 167.36 },

}
