# Mission: Master Cloudflare Kitesurf & Agent-First Browser Automation

## User Goal
To understand Cloudflare Kitesurf architecture, how V8 isolate browser execution works, and how agents leverage the `kitesurf` skill for ultra-fast, stateless web browsing and automation at edge scale.

## Core Outcomes
1. Comprehend V8 Isolate vs Containerized Chromium execution models.
2. Master Markdown/DOM extraction, visual snapshotting, and action sequences in Kitesurf.
3. Understand agent triggering, error handling, and memory lifecycle in Kitesurf agentic workflows.
