# Glimmer Steering

Use Jetpack XR / Compose Glimmer only for Android XR display-glasses UI.

Read the complete installed/current Glimmer skill/docs when the feature touches it. Apply all relevant hardware, lifecycle, interaction, typography, focus, accessibility, performance, and verification guidance.

Keep Glimmer/Android XR code behind the Android XR platform boundary. Shared KMP owns domain state/intents.

Do not treat Glimmer as the Meta DAT UI/runtime. Meta DAT and Android XR/Glimmer remain separate integration paths.

Prefer glanceable, minimal, legible display UI rather than transplanting phone UI. Verify supported hardware behavior when the feature depends on XR/display-glasses semantics.
